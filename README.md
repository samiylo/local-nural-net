# local-nural-net

Spring Boot 4.1.1 starter (Java 21, Maven).

## Requirements

- Java 21+
- Maven 3.6.3+ (or use the included wrapper)

## Run

```bash
./mvnw spring-boot:run
```

## Test

```bash
./mvnw test
```

## Package

```bash
./mvnw package
java -jar target/local-nural-net-0.0.1-SNAPSHOT.jar
```
